Pada gambar tersebut terlihat hasil menjalankan program pemesanan hotel melalui Visual Studio Code. Program ini meminta pengguna untuk memasukkan beberapa data, yaitu jenis kamar, tanggal check-in, dan tanggal check-out.
Pada percobaan pertama, pengguna memilih kamar standard dengan tanggal check-in 08-06-2008 dan check-out 17-06-2008. Dari tanggal tersebut program berhasil menghitung lama menginap, yaitu 9 malam. Setelah itu program menampilkan kembali data pemesanan seperti jenis kamar, tanggal masuk, tanggal keluar, dan lama menginap.
Kemudian program dijalankan lagi dengan memilih kamar deluxe. Tanggal check-in yang dimasukkan adalah 08-06-2008, sedangkan tanggal check-out 10-06-2008. Dari perhitungan tersebut didapatkan lama menginap selama 2 malam.
Jadi, dari output yang terlihat, bagian input data dan perhitungan lama menginap sudah berjalan dengan baik. Tetapi pada bagian total biaya masih tertulis Rp 0, yang berarti perhitungan harga kamar belum menghasilkan nilai atau tarif kamar belum diterapkan pada program.
